# 产品说明书

提取这款游戏的**策划**和**美术**，再用 **TapTap Maker** 做成玩法一模一样的新游戏。

不重打包原 APK。不分析商业化。角色名、Logo 换成自己的，玩法必须一样。

---

## 怎么走

```
APK ──► 机器解包 raw/
     ──► 提取美术  output/assets/
     ──► 提取策划  output/策划/02-核心玩法.md
     ──► Maker 新游戏  output/scripts/ + assets/
```

`output/` 就是 TapTap Maker 工程，也就是新游戏。

Agent 通道（`--via sdk|grok|codex|dsh`）跑同一份任务文案，全文只在 `src/gameaihack/agent/prompts/mission.py`。

---

## 成功线

1. `output/assets/image/` 有从原包抽出的玩法贴图
2. `策划/02-核心玩法.md` 是完整 **游戏 PRD 设计稿**（细到能直接开发）
3. `scripts/main.lua` 用这些图实现同一套核心玩法（至少第一关能打完）

只交文档不算完成。

---

## 不是什么

- 不是解剖包 / 20 维雷达交付
- 不是对照图墙给人手工重绘
- 不是「再写第一局」的独立步骤——提取完就做成游戏

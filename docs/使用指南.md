# 使用指南

提取策划和美术，再用 TapTap Maker 做成玩法一模一样的新游戏。

## 命令

```
gameaihack doctor
gameaihack analyze <apk|包名> --i-have-rights [--via sdk|grok|codex|dsh]
gameaihack build <job_dir> [--to ./游戏.zip]
```

`analyze` 会：解包 → 提取美术到 `output/assets/` → 写出玩法 PRD → 在 `output/` 做成 Maker 游戏。

`build` 把 `output/` 打成游戏 zip。

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -e '.[dsh]'
bash scripts/bootstrap_macos.sh
cp .env.example .env
gameaihack doctor
gameaihack analyze game.apk --i-have-rights --via grok
gameaihack build ./jobs/<包名>
```

非 TTY 必须加 `--i-have-rights`。不要把 `jobs/` 整目录（含 raw）发到网盘。

# 输出物规格 — 解剖包合同

接收者拿到的东西必须稳定。操作者的 `jobs/` 可以脏，`deliverable/` 不行。

`share` 的 zip 解压后就是本规格。版本跟 GameIR 主版本走。

Phase 0 已按本规格写出空骨架：`COVER.md` / `README.md` / `index.html` / `design/00` / `machine/game.ir.json` / 空的 levels·tables·assets。资源墙和关卡画廊从 Phase 1 开始填。

---

禁止出现：

- 原 `apk/obb/xapk`

- 明文密钥、token
- 可安装的重打包

## 2. 封面 `COVER.md` 必含

1. 游戏名 / 包名 / 版本 / 分析时间 / 工具版本
2. 一句话品类（例：竖屏合成 + 轻战斗，内购+广告）
3. 输入完整度（缺 OBB？缺热更？）
4. 雷达 20 维分数表
5. 三张循环图的文字版（各不超过 8 个节点）
6. 主要风险（服务端关卡 / 加密 / 加固）
7. 建议下一步（补材料 / 换 deep / 人工看哪一章）

封面不得出现大段 Lore。

---

## 3. `README.md` 必含（接收者）

见 `docs/templates/交付包README.md`。角色导航锁死：

- 制作人 → `COVER.md`
- 策划 → `design/` + `levels/gallery.html` + `tables/`
- 程序 → `design/08-...` + `machine/` + `feel/`
- 美术 → `assets/` + 表现语言章节
- AI → `machine/game.ir.json` + `claims.json`

---

## 4. 主张 `claims.json`

```json
{
  "id": "claim_econ_01",
  "dimension": 10,
  "severity": "confirmed",
  "text": "存在体力，上限 120，每 6 分钟回复 1",
  "confidence": "high",
  "evidence": [
    {"path": "ir/tables/stamina.json", "extractor": "unity.scriptable_object", "locator": "max=120"}
  ]
}
```

`severity`：`confirmed | hypothesis | unknown`  
`confirmed` 必须有 evidence。HTML 里点击主张弹出证据。

GDD 各章由 claims 渲染而来，禁止模型另写一套对不上的正文。

---

## 5. 雷达 `coverage.json`

每一维：

```json
{
  "dimension": "economy",
  "score": 4,
  "max": 5,
  "evidence_count": 12,
  "blockers": ["shop_prices_in_server"],
  "mode_needed_to_improve": "deep"
}
```

分数定义（对人解释用，写进 COVER）：

| 分 | 含义 |
|---|---|
| 0 | 完全没碰到 |
| 1 | 只有蛛丝马迹 |
| 2 | 知道有这个系统，细节不足 |
| 3 | 可开会讨论，缺公式或缺部分内容 |
| 4 | 表/关卡/UI 对得上，少量缺口 |
| 5 | 证据充分，模拟也自洽 |

---

## 6. 关卡 `level.json`

与 `ir-schema.md` 的 Level 一致，另加给接收者的字段：

- `rebuild_grade`: L0–L3
- `teaching`: 本关新出现的机制标签（可空）
- `density`: 实体密度等可计算指标（可空）
- `preview`: 相对路径，可缺

`levels/index.json` 按游玩顺序。顺序未知则按 id，并声明 `order=unknown`。

---

## 7. 表

- Excel 友好 CSV（UTF-8 BOM 可选，Excel 打开中文不乱码）
- `index.csv` 列：`id,role,rows,schema_state,source`
- `schema_state=inferred` 的表在文件头注释一行：`# schema inferred, 列名可能错`

---

## 8. 资源目录

`assets/catalog.json` 每条：

- 可读 `name`（引用反查 + LLM 辅助，保留 `original_path`）
- `kind`、`used_in_levels`、`used_in_entities`
- `thumb`、可选 `full`

`share` 默认只带 thumbs。`--full-assets` 才带原图，仍不含 apk。

---

## 9. HTML 最低交互（没有就不算能给别人用）

双击 `index.html` 必须能：

1. 看雷达和封面
2. 搜资源（按名、按类型）
3. 开关卡画廊，点进单关 JSON
4. 打开表（前 200 行 + 下载 CSV）
5. 点 GDD 主张看证据
6. 看未知项和下一步

不做登录、不做后端。图全是相对路径。

若浏览器拦截 file:// 下的 JS：包内附 `OPEN.txt`，写一条 `python -m http.server`。

---

## 10. 体积预算（share 默认）

| 部分 | 预算 |
|---|---|
| thumbs + HTML + md + csv | 尽量 < 200MB |
| 关卡 preview | 每关一张 ≤ 300KB |
| full assets | 不进默认 zip |
| machine IR | 表全量可在 machine，HTML 只 preview |

超预算时：先丢 full、再降 preview 分辨率，不丢 claims 和表。

---

## 11. LEGAL.txt 最低内容

- 本包是分析产物，不含游戏安装包
- 素材版权归原权利人，仅供授权范围内的研究 / 对照 / 内部评审
- 禁止把本包当素材再分发、上架、训练公开模型（除非权利人书面允许）
- 分析工具版本与日期

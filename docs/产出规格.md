# 产出规格

`output/` 就是 TapTap Maker 工程，也就是新游戏。

```
jobs/<包名>/
  raw/                      解包，不外发
  output/
    策划/02-核心玩法.md      游戏 PRD（至少 5000 字，含核心循环/操作/场上物/第一关/验收）
    assets/image/            提取的美术
    assets/audio/
    scripts/main.lua         同一套玩法
    .project/                Maker init 之后
  <包名>-game.zip            gameaihack build 打出的游戏包
  run.log
```

`build` 把 `output/` 打成 zip（不含 apk/so）。
